# C++ FFI Wrapper

This directory contains the main FFI wrapper that exposes the oZKS (OpenZKS) commitment scheme functionality to Rust code.

## Overview

`cpp_wrapper.h` and `cpp_wrapper.cpp` provide a C interface to the underlying oZKS C++ library, making it accessible from Rust through FFI bindings.

## Public Functions

All functions are exported with C linkage and follow this naming convention: `ozks_*`

### Initialization
- `ozks_init_sqlite()` - Initialize SQLite storage backend

### Instance Management
- `ozks_create()` - Create a new OZKS instance
- `ozks_destroy()` - Destroy an OZKS instance
- `ozks_get_id()` - Get the ID of an OZKS instance

### Data Operations
- `ozks_insert_batch()` - Insert a batch of key-value pairs
- `ozks_flush()` - Flush pending operations to storage
- `ozks_query()` - Query a key's value and membership status

### Commitment & Proofs
- `ozks_get_commitment()` - Get the current commitment
- `ozks_get_commitment_serialized()` - Get serialized commitment bytes
- `ozks_query_proof()` - Get proof for a key membership query

### Serialization
- `ozks_save()` - Serialize and save OZKS state
- `ozks_load()` - Load OZKS state from serialized data

### Key Management
- `ozks_get_vrf_secret_key()` - Retrieve VRF secret key
- `ozks_set_vrf_secret_key()` - Set VRF secret key

## FFI Safety Considerations

1. **Opaque Handles**: `OZKSHandle` is an opaque pointer - Rust code should not dereference it
2. **Memory Management**:
   - Handles created with `ozks_create()` must be freed with `ozks_destroy()`
   - Ownership transfers at boundaries
3. **Error Handling**: Functions return error codes; Rust wrappers should check return values
4. **Thread Safety**: Verify whether oZKS instances are thread-safe before concurrent access

## Rust Integration

Rust code includes generated bindings from this header:
- Bindings generated by `bindgen` in `build.rs`
- Located in Rust code as imported FFI declarations
- Safe wrapper functions in `src/ozks_lib/wrapper.rs` abstract unsafe FFI details

## Compilation

Compiled as part of the `ozks_wrapper` static library during `cargo build`.
